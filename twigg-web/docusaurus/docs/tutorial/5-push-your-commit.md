# 5. Push your commit
In the last step you created a commit on your computer.
To have it reviewed and submitted, you must **push** it to the server.
Run the following command:
```
tw push
```
Running `tw` will show you that the commit was pushed:
```
@ #1v0 c/1v0 Pushed
| My first commit!
* #0 c/0v0 Submitted
| [Initialize]
```
Also, the commit now has a *server id* `c/1v0`

<kbd>CTRL</kbd>+<kbd>Click</kbd> `c/1v0` to open the commit in Twigg.

Add a description, and now your commit is ready for review.
