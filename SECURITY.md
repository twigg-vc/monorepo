# Security Policy

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public issues,
commits, or public Discord channels.

Instead, report them privately via email: `security@twigg.vc`

Please include as much of the following as you can: a description of the
issue, steps to reproduce, affected component (twigg-web, twigg-track,
tw CLI, VS Code extension), and any potential impact.

We genuinely appreciate every report! We'll gladly credit you in the fix unless
you prefer to stay anonymous.
